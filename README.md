# Ziv｜工具作品集

靜態網站，托管在 Cloudflare Pages，`git push` 自動部署（做法同 `vita-lectionis`、`folia-domestica`）。

## 這個網站是什麼

自己的資產：未來換工作／轉型時，用來證明做過什麼。
**不是** SOP、不是給同事照做的操作手冊。

## 公開邊界（2026-08-04 定，動內容前先看這條）

- 不放公司、客戶、真實檔案或真實印章
- 不放特定作業情境
- 未實際量測的效益，不宣稱（例如「省下 N 分鐘」）
- 案例文字以「已脫敏版」為準，不使用 repo 內含公司描述的長版草稿

## 結構

```
index.html        首頁：定位 + 案例入口

```
